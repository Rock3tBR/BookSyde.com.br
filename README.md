# BookSyde

Arquitetura em migração controlada para frontend React/TypeScript e backend Java/Spring Boot.

- `front/`: aplicação web atual.
- `back/`: API REST e regras server-side.
- `docs/`: arquitetura, execução, segurança e status da migração.

Consulte `docs/RUNBOOK.md` antes de executar/deployar. Não remova rotas legadas até os fluxos equivalentes Java terem sido validados end-to-end.
